# 1.6.4 — 半自动的左侧按钮回到「自动 开/关」

Spire Pilot 是《杀戮尖塔》的战斗求解 mod：点一下「计算」，它把这场战斗算到结束，在面板上给出路线。
1.6.3 在半自动里把左侧按钮改成了「执行一步」；实际用下来，单步没有独立价值——想连续打仍要开自动。
这一版把它改回两种模式通用的「自动 开/关」。

完整版本历史见 [CHANGELOG.md](../CHANGELOG.md)。

## 下载

- `spire-pilot-1.6.4.jar`
- 依赖：ModTheSpire 3.30.0+、BaseMod
- 适配游戏版本：12-18-2022（最终版）

## 这一版改了什么

### 左侧按钮：两种模式都是「自动 开/关」

- **半自动**：点「自动 开」，算好的路线会按「节奏」连续执行；**路线走完就停**，不会再自己重算。
- **全自动**：同样是「自动 开/关」，路线走完会自动重算，直到战斗结束。
- 两种模式的区别只在路线走完之后，按钮语义完全一致，不需要记两套操作。

### 逐步执行仍然可用

想停在计划的某一步，直接点路线里那一步的药丸（右侧的步骤按钮）：
它会先执行到那一步，然后停下等你。每一步执行后仍会比对摘要，不符即作废整条路线。

### 不变的部分

右侧仍是「半自动 ✓ / 全自动 ✓」模式切换；全自动下不会出现步进键。
1.6.3 的「计算等怪物意图确定」保持原样：意图还是 `DEBUG` 时按「计算」会排队并显示
「等怪物的意图出来就开始计算…」，4 秒仍是无滚动意图 mod 的逃生上限。
