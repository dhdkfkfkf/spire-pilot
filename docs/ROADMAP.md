## 5. 术语：两个「A/B」不是一件事（用户 m10771 的疑问）

1. **搜索方案 A vs 方案 B**：A=继续用真引擎（加深/排序），B=另写一份数值代理。这是**二选一**，早就选了 A，B 永久否决。
   A 内部四个小项：A0 用满预算 ✅ 已落地、A3 延后队列 ✅ 已落地、A1 试算排序 ❌ 实测否决、A2 支配剪枝 ❌ 否决。
   见 `docs/SEARCH-OPTIONS.md`。
2. **选牌时的「A/B」**：同一场遭遇，分别带候选牌 1 和候选牌 2 各打一遍比较掉血。这是**方法名**（成对试打），不是待选方案。
   见 `RUNMAP-PLAN.md` §4b。

## 6. 顺序与风险

- 顺序固定 P5-1 → P5-2 → P5-3 → P5-4 → P5-5 → P5-6：后一步都需要前一步的数字；P5-1 的数字你可以用直觉当场判对错。
- **最大风险是 P5-5**：不是算力，而是九种屏幕的点击接口要一个个去游戏里核实；某个屏卡住就多半天。
- 每阶段结束都要 build → install → 全套门禁（495 项，十几分钟）→ evidence → 文档，20–40 分钟。
- 估时不含实机复测与需求变更的返工。
