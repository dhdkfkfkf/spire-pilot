# 《普通人用 DSH 做 Mod 有多难》脚本 v2 —— 改成"离谱科普"长视频节奏

> 参考风格：抖音/B 站「XX 究竟有多离谱」类长视频（如《MC 的矛究竟有多强大？MOJANG 近年来最大胆的设计》）。
> 骨架：**极端现象开场 → 抛承诺 → 三层递进（每层解决一个问题、同时抛下一个）→ 结尾回扣开场那一幕**。
> 与 v1 的核心差别：v1 是电影式（慢、留白、情绪）；v2 是科普式（快、密、每个 30 秒一个可记住的细节）。

---

## 1. 这类长视频为什么"显得有内容"

不是靠时长，是靠**每 60–90 秒一次的"重新下钩"**：

| 手法 | 具体做法 | 在本片里的落点 |
|---|---|---|
| 极端现象开场 | 先给最反常识的一幕，不解释 | 面板算完三回合、无伤通关 |
| 立刻给代价 | 用数字把"离谱"锚定 | 3 次推倒 / 58,604 次调用 / 5,400 万 token |
| 每层一个小结论 | 说完就抛新问题 | "动画不是根本问题" → 转第二版 |
| 主动替观众提问 | "你可能会问……" | "为什么第二版更贵却更差？" |
| 具体到细节 | 数字、原话、bug 名，不放形容词 | 12 点意图、幽灵动作、多 3 点血 |
| 结尾回扣 | 重放开场画面，换一句注解 | 三行日期，第三行加"成品" |

**密度标准**：每 30 秒至少出现一个"可截图"的东西（数字、原话、示意图、bug 面板）。达不到就删旁白。

## 3. 逐段脚本 v2

### 【0:00–0:12】开场：先给最离谱的一幕

**画面**：0.3 秒黑屏 → 直接切实机。面板弹出三条路线，鼠标点"计算"，0.8 秒出结果，自动出牌三连，结算无伤。全程不要解说字幕。
**旁白**（快，平）：
"注意看这个面板。它算出了接下来三个回合的全部出牌顺序，然后自己把这场打完了——一滴血没掉。"
"而这东西，是我用一个聊天框做出来的。我没写过一行卡牌代码。"

## 4. 画面节奏硬规定（v2 的关键差异）

1. **平均每 6–10 秒必须有一次画面变化**（切镜头 / 出字幕卡 / 推近 / 数据动画）。任何静止画面不超过 8 秒。
2. 旁白不停，音乐不停；只在 4 个转折点做 2 秒静音（3:10、6:45、8:50、12:40）。
3. 每段开头不做空镜留白（v1 的做法），直接进画面——科普向观众不吃留白。
4. 字幕卡不念，字幕卡是给"静音观看"的人看的；旁白说人话，字幕给关键词。
5. 数字出现必须配一声键盘或计数音，否则观众会漏掉。

## 5. v1 → v2 的取舍

| 项 | v1（电影式） | v2（科普式） |
|---|---|---|
| 开场 | 黑屏三行日期，慢 | 直接成品画面，3 秒给结果 |
| 节奏 | 留白、呼吸 | 每 6–10 秒切一次 |
| 叙事 | 情绪驱动 | 问题驱动（每层一个小结论） |
| 数据 | 少量、克制 | 密集，每 90 秒一个数字 |
| 结尾 | 抒情 | 回扣开场 + 一句观点 |
| 风险 | 前 40 秒可能掉人 | 信息密度高，剪辑量大 |

**建议**：主线用 v2 的节奏，但保留 v1 的两个"慢镜头"——154 格方阵熄灭（3 秒静音）和结尾黑屏 2 秒。一紧一松，才有"内容感"。
