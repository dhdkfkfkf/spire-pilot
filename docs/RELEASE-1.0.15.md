# 1.0.15 — 牌多、怪多、怪血厚时不再让你干等

上一个公开版本：**1.0.3**。这一版把"搜索会拖很久"这件事拆成了可解释的预算、阶段与交付规则，并修掉了一个会直接崩溃的渲染问题。

## 这一版做了什么

### 1. 崩溃：空纹理不再打死游戏

过去遇到球、能力图标、闪光效果、治疗面板上的空纹理，`SpriteBatch.switchTexture` 会直接 `NullPointerException`（它拿到纹理后第一句就是 `getWidth()`）。1.0.5 的第一版守在四个"猜出来的字段"上，只能挡住一部分。

现在改为守唯一入口：`switchTexture` 前置拦截，纹理不可用时不执行原方法，而是刷新批次并换上一张已加载的占位纹理。同一个调用点只记录一次完整栈：

```
tex: unusable texture (null) reached SpriteBatch.switchTexture; placeholder=true;
     first call site: <真正画它的那行>
```

启动日志里的 `tex guard: active` 表示补丁确实挂上了 libgdx 的类。**这一条是"打了别的角色 mod 后启动就崩"的直接对症**。

### 2. 推演深度：默认只算最近 3 回合

旧行为是把整场战斗推到结束才敢说话，血厚或多怪时会一直等。

- `search.horizonTurns`（默认 3）：只展开到当前回合 +3 回合；到线的节点不再克隆，用它已有的评分参与竞争；执行一步后从新局面重搜。`0` 回到"推到结束"。
- 收敛即停：连续 6 层最优分不动且已跨过回合边界，提前结束。
- 非斩杀局面不再把败线补到战斗结束。

### 3. 预算：按场面算，也有硬上限

「秒数」按钮现在是一条档位：

```
自动 → 自动(6s) → 自动(12s) → 自动(18s) → 自动(30s) → 自动(60s) → 无限
```

- `自动` 按眼前的场面算：`4 + 2×活怪数 + Σ(血量+护盾)/40 + 动作项`，夹 6–90 秒，BOSS 房翻倍。
- 动作项 = `手牌 + 本回合已打出`，超过 5 的部分每点 +0.5 秒，最多 +6 秒。**这一项专门为"每打一张抽一张、手牌上限却只有 5"的角色准备**：手牌数看起来没变，一回合却能连着打十几张。
- 搜索进行中，如果沙箱里某一回合链到比开局更多的动作数，按实际峰值再延长等待（每点 +0.4 秒，最多 +6 秒）。只有 `自动` 会延长；6/12/18/30/60 是你选的数字，属于承诺。

### 4. 阶段降级：到时间就退到 2 回合、1 回合

用到预算的 45% 还没走完 2 回合，承诺降到 2 回合；用到 75% 连 1 回合都没走完，只保 1 回合。日志写两行：

```
stage: 6s of 12s used, 1 turn(s) finished; promise lowered to 1 turn(s)
```

### 5. 交付规则：默认不给半回合

全程记录"真正走完过回合"的最好一条线，收尾时若最优线停在本回合中间而存在走完回合的线，交付后者。只有单回合动作数 ≥ 20 时才允许半回合——那时凑满一回合的克隆代价已经超过收益。

### 6. 目标后置：单体牌不再乘上怪物数

每张单体牌过去对每只活怪各开一条分支、各克隆一次沙箱。现在按「同一张牌（含升级/费用）」分组，只保留三类目标：能斩杀、意图伤害最高、有效血量最低。组内任一目标带能力（荆棘、缓冲、愤怒、人工制品、mod 自带 power）时整组保留——这些怪换目标结果真会变，不猜。

### 7. 「计算」可以重算

同一局面再按「计算」过去只会命中计划缓存、返回旧答案。现在手动按键绕过一次缓存：

- 计算中按键 = 收尾，交出当前最优；
- 已有结果时按键 = 重新计算。

### 8. 搜索质量

- 回合级排序（`search.turnPlan`）：先用手牌 0/1 背包算"这回合能不能杀"，再用怪物意图算"必须不必须防"，据此把斩杀、防御、药水候选排前面。只排序不删分支——估错只花时间，不丢答案。
- 束宽多样性（`search.diversity`）：一层被截断时按动作类型各保底一个，再按分数填满，避免整条束都是攻击牌。
- 克隆器身份表按上次规模预分配，降低每次 fork 的扩容开销。

## 开关一览

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `search.horizonTurns` | `3` | 推演回合上限；`0` = 推到结束 |
| `search.targetFocus` | 开 | 单体牌只保留关键目标 |
| `search.turnPlan` | 开 | 回合级候选排序 |
| `search.diversity` | 开 | 束宽动作类型多样性 |
| `search.dominance` | 关 | 同层格挡更少的状态直接丢 |
| `search.symmetricTargets` | 关 | 合并外观完全相同的怪 |
| `panel.timing` | 关 | 状态行显示本帧耗时 |

## 兼容性

- 只增加内容（卡牌、遗物、药水、角色、怪物、事件）的 mod，理论上一律兼容，因为求解器调用的是游戏自身代码。
- 改写伤害计算、动作队列、回合结构或抽洗牌顺序的 mod 可能让模拟与实机不一致。
- 纹理守卫会在日志里点名"是谁画了坏纹理"，便于向对应 mod 反馈。
- 已实测：原版；原版 + 菜农 mod。

## 已知边界

- 预算内最好不等于全局最优；手牌与怪物极多的局面可能只覆盖半回合。
- 未展开的分支会在面板底部列出，那些分支上的路线不一定最优。
- 纹理守卫只阻止"空纹理崩溃"，被替换的位置显示占位图，不影响结算。
