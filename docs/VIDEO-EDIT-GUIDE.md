# 剪辑排版指南（怎么排视频、怎么排字幕）

> 配套成片：`video-out/v7-横屏-6分25.mp4`（B 档 +8%，6:25.2）
> 镜头表由 `_tmp/film.py` 的 SHOTS 与 47 句配音时长直接算出，可用于剪映手工复刻或逐段校对。

## 一、怎么排视频（轨道结构）

### 1. 主轨（V1）：41 个镜头，首尾相接，不留空隙
- 每个镜头只有一个任务：**画面只服务当前这一句旁白**，不叠加第二个信息。
- 镜头类型只有四种，复刻时不要新增第五种：
  1. **实拍**（游戏 / DSH 界面 / 网页）：不加转场，硬切；
  2. **实拍定格 + 缓推**：截图定格后做 100%→103% 的缓慢推近（剪映：图片 → 关键帧缩放），用于必须在静止画面上读字的段落（用量页、插件列表）；
  3. **示意场景**（代码绘制）：黑底 + 网格 + 单色线条，只画"关系"，不画写实；
  4. **黑场字卡**：全黑底 + 一行主标题 + 一行副标题，用于段落结论。
- **转场只有两种**：硬切（95%）、章节处 0.25s 淡入/淡出黑（剪映：叠化 + 黑场，或"变黑"转场时长 0.25s）。全片不用推拉/翻页/闪烁转场。

### 2. 章节结构（4 章 + 开场 + 收尾）
| 章 | 时间 | 内容 | 进入方式 |
|---|---|---|---|
| 开场 | 0:00–0:45 | 是什么 → 工具长什么样 → 成本与三次尝试 | 直接进画面 |
| 第一章 | 0:45–1:24 | 九月二十九日的第一条消息、我的误判 | 淡入 |
| 第二章 | 1:24–3:47 | 第一版（实机重置）与第二版（重写卡牌），含 327 元的结论 | 硬切 |
| 第三章 | 3:47–5:20 | 插件、判据、沙盒复制、beam、遗漏的边界 | 淡入 |
| 收尾 | 5:20–6:25 | 三件更硬的事 + 结尾两句 | 硬切 |

### 3. 节奏硬规定
- 平均每 **9–10 秒**换一次画面（本片 41 镜 / 385 秒）。
- 每个镜头的时长 = 它包含的那几句配音时长之和 + 0.45s 间隔，**不要为了卡点剪掉尾音**。
- 数据类镜头（用量、遗物格、8.9 亿）必须让数字**动起来**（计数/逐格填），静态数字停留不超过 2 秒。

## 二、怎么排字幕

### 1. 一行一句，永远只显示一行
- 位置：横屏 **距底 74px**（`y = 1080-74`），水平居中；不要抬到画面中部，不要在上下同时出字。
- 字号 **46px**（1080 高），字重 Bold，颜色 **#ECECEC**，透明度 100%。
- 描边去掉，改为 **1px 深色阴影（#101010，向下偏移 1px）**；字幕下方叠一条 **190px 高的黑色渐变带**（底部 55% 不透明 → 顶部 0），保证压在任何亮画面上都能读。

### 2. 断句规则（按标点，不按字数）
- 先按 `。！？` 切成句；句内再按 `，、；：` 切成小句。
- **一行只装整数个小句**，装不下就整句下沉到下一行，绝不把词拆开（例："用 DeepSeek Harness 做的" 不能被切开）。
- 单行超过 **18 个汉字**（含标点）时，先缩字号到 40px；仍然超宽才允许在该小句内部断。
- 每行的显示时长按**该行字数占比**分配整句时长，所以长句的换行是匀速的，不会一行闪得特别快。

### 3. 时间对齐
- 每句字幕的起点 = 该句配音起点（不是镜头起点），句间留 0.45s 空档时字幕也同步消失，下一句出现。
- 不要给字幕加"打字机"或"逐字弹出"，只用 **0.12s 淡入**。

## 三、导出与素材规格
- 工程 1920×1080 / 30fps；导出 H.264、CRF 20、preset veryfast、yuv420p、AAC 192k。
- 实拍素材原始为 1280×720，放大到 1920 宽时加 `unsharp` 轻锐化（剪映：调节-锐化 +8），否则面板小字发虚。
- 音频：人声 -14 LUFS 左右，背景音乐压到 -30 dB 以下（本片无 BGM，只有人声）。
