## 面板（本轮对齐 STS2 的重点）

STS2 的 `SolverRouteRow` 是"回合 + 动作 pill + 右侧结果列"。STS1 这边是单字体文本面板，等价信息：

```
STS1 Engine Solver  [win line found]
可赢 · 预计掉血 10 · 3 回合 · 778 节点 · 1.2s
第 1 回合            HP 74  能量 0
▶1. 燃烧
  2. 打击 → 邪教徒    敌 51/51
  3. 打击 → 邪教徒    敌 51/51
  4. 结束回合          → 第 1 回合结束
第 2 回合            HP 80  能量 3
  ...
未展开（会打开选择提示）: Prepared, Survivor 等 2 张
F8 重算 · F9 下一步 · F10 整条 · F11 收起 · F12 演示
```

并且**画面上的指向**（STS2 也有）：

- 当前步要打的那张手牌 → 高亮框；
- 目标怪物 → 红色高亮框 + 一条虚线连到卡上；
- 结束回合 → 高亮 End Turn 按钮；
- 自身增益/药水没有目标时**不画**目标框（诚实，而不是随便指一个怪）。

仍然缺的（与 STS2 的差距）：可点击动作条、回合折叠、遗物触发行、药水图标、循环/组合行、
战前 dequeued 动作。这些是"面板是控件树"带来的能力，STS1 这版是"单块文本 + 画面标记"。
