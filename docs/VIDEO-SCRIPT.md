## 4. 让片子"显得高级"的 6 个具体动作

1. **少即是贵**：全片只用两种字体、一个强调色、三种转场。花哨是廉价的信号。
2. **留白即节奏**：每个大段落开头留 1.5 秒空镜 + 环境音，不要用旁白填满。
3. **数字只给两个**：一屏最多两个数字，且必须有一句人话解释它意味着什么。
4. **引语用原话，不用转述**：用户消息原文（错别字也保留）比任何总结都有质感。
5. **坦诚即高级**：直接说"前两版没有画面""我删了"，比伪造录屏高级一百倍。
6. **声音决定档次**：底噪 + 低频 hit + 键盘声，成本几乎为零，但 80% 的"高级感"来自它。

## 5. 可行性判断

- **题材**：稀缺。B 站"AI 做 mod"很多，但绝大多数是"一次成功"的爽文；你有三次真实失败 + 可量化代价 + 一个技术洞察，这是差异化。
- **素材**：够用。成品录屏可补录；前两版用物证（表、报告、脚本）替代画面，反而更有纪录片感。
- **难点**：①13 分钟需要约 3500 字旁白，配音/剪辑工作量最大；②前两版的"技术解释"容易讲干，必须靠示意图和比喻（"重置了数据没重置世界""复制世界不重写规则"）。
- **风险控制**：若时间不够，先做 8 分钟版——砍掉 §10:40 的分屏对比和可选翻车段，主线三幕仍然完整。
