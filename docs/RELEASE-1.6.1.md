# 1.6.1 — 右侧变成仪表盘，左侧开始说人话

Spire Pilot 是《杀戮尖塔》的战斗求解 mod：点一下「计算」，它把这场战斗算到结束，在面板上给出路线。
这一版没有新算法，改的是面板怎么说话——把说明书腔和引擎术语换成玩家能直接读懂的句子。
右侧仪表盘的重做（10×10 像素阵、洗牌点亮、纯数字承诺槽）也在这条版本线上一起交付。

完整版本历史见 [CHANGELOG.md](../CHANGELOG.md)。

## 下载

- `spire-pilot-1.6.1.jar`
- 依赖：ModTheSpire 3.30.0+、BaseMod
- 适配游戏版本：12-18-2022（最终版）

## 这一版改了什么

### 1. 左侧文案：从说明书改成说人话

标题行过去会漏出内部状态英文，玩家截图里真实出现过 `Spire Pilot  [idle]`。现在：

- `idle` → `待命`，`计算中…` → `计算中`，搜索异常 → `计算出错，详情见日志`（原始内容仍在日志里）。
- 「计算」路径：`已用 Ns（不限，一直算到分叉跑完或再点「计算」）` →
  `已算 N 秒 · 没有时限，算到分叉跑完，或你再点一次`。
- `最优 N 步（未证明）  窄搜 beam=10 layers=69` → `当前最优 N 步（还没找到能赢的线）` /
  `（还没证明最优）`。引擎自己那套词汇不再上屏，节点数也不再和副标题重复。
- 暂定路线：`暂定路线 · 还在算，没回放校验过 · N 步`。
- 停滞提示：`⚠ 已经 N 秒没有新进展，可能卡在某次结算上；再点「计算」可以停`。
- 空闲提示：`点「计算」，让我把这场算一遍`。
- 降档说明：`会算到战斗结束 · 已走完 N 回合` / `只往前看 N 回合` /
  `（时间不够，从 X 回合缩到 Y）` / `（时间不够，从算到底缩到 N 回合）`。
- 深度搜索（Shift+F8）：`已用 Ns（不限） 节点 N 最优 N 步` →
  `已算 N 秒 · 没有时限 · N 条世界线 · 当前最优 N 步`；预算版带 `还剩 N 秒`；
  收尾句 → `再点「计算」就停下，手里这条最优线会留着`。`phase()` 这类引擎词从两条分支一起拿掉。
- 门禁依赖的契约串（条世界线、计算中、已查阅、暂定路线、打赢后固定回血）原样保留，
  S114 的禁词（预计掉血 / 第 / 回合：）仍未出现。

### 2. 像素阵

进度读数不再是横向条，而是一个 10×10 的方形像素场：边长 8、缝 1，整块 89×89，在状态块里水平居中。
状态块随之从 82 长到 157（`4 + 26 + 4 + 26 + 4 + 89 + 4`），面板往下扩，顶边不动。

### 3. 洗牌点亮

格子按一张固定的 100 项排列表点亮，不是按位置。一行行填会读成「方形进度条」，散着亮才读成「一片像素
在活起来」。用固定表而不是每帧 shuffle：同一进度必须点亮同一批格子，否则截图没法解释，两个人看同一个
百分比会看到不同的图。

### 4. 呼吸与前沿闪烁

- 已亮的格子 alpha 走 620ms 正弦，周期约 3.9 秒，慢到不吵。
- 最新点亮的 2 格走 180ms 闪烁，亮度从 `0.310,0.639,1.0` 提到 `0.560,0.820,1.0`。
- 两个波频率不同，不会锁步成一块整体在脉动。
- 搜索停滞时像素仍在呼吸——它只说明「还活着」，不谎报进度。

### 5. 右侧纯数字

承诺槽从「推到战斗结束」/「3 回合最优（已降档）」/「 · 走完 4」改成 `结束` / `3回合` / `3/5回合` /
尾部 ` ·4`。右侧是仪表盘，散文归左侧。

### 6. 左侧文案库扩充

初始化 7 句、搜索 26 句、深搜 9 句、收尾 9 句、完成 6 句。1.5 秒一换，26 条要 39 秒才循环一轮，
慢速搜索时不会背下来。

### 7. 顺带修掉的两个门禁问题

- **S75 的假通过**：无头门禁没有「下一帧」，搜索结束后直接读路线条读到的是空的，套件顺序里靠上一
  门禁的残留行假过。现在先走一次面板同款的 `lines()`，再断言路线条，单跑与套件顺序都成立。
- **S114 的偶发失败**：上一门禁留下的在飞搜索会让「计算」走二连按重启路径；旧搜索空结果时
  `finishQuick()` 提前返回，把新请求吞掉。现在 `reset()` 取消在飞搜索，空结果分支也会兑现重启请求。

### 8. 顺带收进来的 1.5.3

`1.5.3` 的两条门禁修复（S230 / S246，`passes()` 数 rung 而非药水档、`beamWidth()` 补峰值记忆）
也在这一版里；`1.5.1`（进度副文案按秒轮换）与 `1.5.2`（回合数 4/5、按回合数求解不再被时间砍）
同样在这条线上。细节见 CHANGELOG。

## 开关一览

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `search.horizonTurns` | `0` | 回合硬上限；`0` = 推到结束（没有显式上限时才走降档阶梯） |
| `search.targetFocus` | 开 | 单体牌只保留关键目标 |
| `search.turnPlan` | 开 | 回合级候选排序 |
| `search.diversity` | 开 | 束宽动作类型多样性 |
| `search.dominance` | 关 | 同层格挡更少的状态直接丢 |
| `search.symmetricTargets` | 关 | 合并外观完全相同的怪物 |
| `panel.timing` | 关 | 状态行显示本帧耗时 |

## 升级

直接用 `spire-pilot-1.6.1.jar` 覆盖 `mods/spire-pilot.jar` 即可，不需要改配置。
`settings.txt` 里如果手动写过 `search.horizonTurns=3`，那是你自己的硬上限，本版会照旧遵守；
想恢复默认行为请删掉这一行或改成 `0`。

## 已知边界

- 预算内最好不等于全局最优；手牌与怪物极多的局面仍可能只覆盖半回合（动作数 ≥ 20）。
- 未展开的分支会在面板底部列出，那些分支上的路线不一定最优。
- 纹理守卫只阻止「空纹理崩溃」，被替换的位置显示占位图，不影响结算。
